# Returns

## How long you have
Most items can be returned within 10 days of delivery. Electronics and phones have 7 days.
Groceries, innerwear and personal care items can't be returned once opened.

## How to start a return
Open the order in the ShopKart app, choose Return, and pick a reason. A courier collects the item
from the delivery address within two working days. Keep the item in its original box with the tags on.

## When a return is refused
The courier checks the item at pickup. A return is refused if the item is used, damaged by the
customer, or missing parts or the box. The caller can raise a complaint from the order page if they
think the refusal was wrong.
